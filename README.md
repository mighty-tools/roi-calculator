# Mighty Pro ROI Calculator

A 4-step revenue projection tool for Mighty Pro Hosts. Enter audience size and
conversion assumptions across intro, core, and level-up offers to estimate gross
revenue, expenses, net profit, and ROI — with scenarios and a downloadable PDF
summary.

**Live:** https://mighty-tools.github.io/roi-calculator/

## Editing

The whole tool is one self-contained `index.html` (inline CSS + JS; fonts and
Chart.js load from CDNs). Edit it, then publish.

## Publishing

Hosted on GitHub Pages (branch `main`, root) under the `mighty-tools` account.
From the source repo, run:

```bash
bash publish-roi-calculator.sh
```

Pages rebuilds automatically in about a minute.
